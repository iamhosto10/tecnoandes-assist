# Garantía sobre reparaciones

Toda reparación realizada por el servicio técnico de TecnoAndes tiene una garantía de **90 días**
sobre el repuesto instalado y sobre la mano de obra.

Si el mismo problema por el que se llevó el equipo a reparación se repite dentro de ese plazo de
90 días, la re-reparación no tiene costo adicional para el cliente.

Esta garantía de reparación no cubre daños nuevos, causados por golpes, caídas o líquidos,
ocurridos después de que el cliente recibió el equipo reparado.
