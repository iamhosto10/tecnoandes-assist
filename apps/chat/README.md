# apps/chat

Chat del cliente de TecnoAndes Assist (Next.js App Router). Ver el
[`CLAUDE.md`](../../CLAUDE.md) de la raíz del repo para el contexto completo
del proyecto.

## Desarrollo

```bash
# desde la raíz del repo
make chat
```

Necesita el backend corriendo en `localhost:8000` (`make up` desde la raíz).
Por defecto apunta ahí sin configuración adicional — ver `.env.example` si
necesitas apuntar a otro backend.
